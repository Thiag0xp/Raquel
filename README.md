# Carta pra Raquel ♥ (v2)

## Como usar
1. Coloque sua música em `music/musica.mp3`.
2. Abra o `index.html` no navegador (duplo clique).

## Personalizar
- `js/script.js` (topo, em CONFIG): mensagem inicial, quantidade de corações da missão e WhatsApp (para ela te avisar que disse sim).
- `index.html`: textos das outras telas.

## Publicar online (grátis)
Arraste a pasta para netlify.com/drop, ou use GitHub Pages / Vercel.

Fluxo: envelope → mensagem → 7 anos → coração → missão dos corações → pergunta → sim.
